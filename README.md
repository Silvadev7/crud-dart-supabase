1 - Sobre o projeto

Este é um projeto de CRUD desenvolvido em Dart, utilizando o Supabase como banco de dados para armazenar informações de veículos.

O sistema permite adicionar, listar, atualizar e excluir veículos.


2 - Banco de dados

Para utilizar o projeto, é necessário criar uma conta no Supabase e criar um novo projeto.

Depois, acesse o SQL Editor e execute o seguinte comando para criar a tabela:

CREATE TABLE veiculos(
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    marca varchar(50),
    modelo varchar(100),
    ano INTEGER,
    valor DECIMAL(12, 2),
    quilometragem INTEGER
)

3 - Configuração

Na pasta principal do projeto, crie um arquivo .env e coloque as informações de conexão do seu projeto Supabase:

SUPABASE_URL=sua_url
SUPABASE_PUBLISHABLE_KEY=sua_chave

4 - Como executar

Primeiro, instale as dependências: dart pub get

Depois, execute o projeto: dart run
